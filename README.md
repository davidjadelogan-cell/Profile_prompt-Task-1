# Profile_prompt-Task-1
## Description
This is a program that collects and validates a user’s profile information and saves it in a Json file

The program:
- Collects user details 
- Validates user input
- Saves the profile information into a `profile.json` file
- Reads and displays the saved profile summary

The profile summary is automatically saved in the same directory as the main Python file for easy access and sharing.

Characteristics
- Input validation for:
  - Name
  - Age
  - Nationality
  - Education level
- JSON file handling using Python's built-in `json` module
- File path handling using Python's built-in `os` module
- Error handling using `try` and `except`
- Profile summary display

---

Technology
- Python 3


## Required Libraries
This project uses only Python built-in libraries:
- import os
- import json
